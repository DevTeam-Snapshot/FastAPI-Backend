Snapshot Backend API 명세

7. 주요 필드 설명

React는 모델을 직접 호출하지 않습니다. 현재 화면 상태와 사용자 입력을 FastAPI에 보내고, FastAPI 응답을 화면 상태에 반영합니다.

기획 대화 Request Body

필드형식React에서의 역할
user_messagestring사용자가 이번 차례에 새로 입력한 답변입니다.
current_stepstring현재 질문 카테고리입니다. 응답의 next_step을 다음 요청에 사용합니다.
briefobject지금까지 React가 임시 보관한 전체 기획서입니다. 매 요청마다 최신 값을 보냅니다.
conversation_historyobject[]모델이 문맥을 판단할 최근 대화입니다. 최대 12개이며 직전 질문만 보내는 방식도 가능합니다.

임시 기획서 brief

필드역할
lodging_type숙소 유형: hotel, motel, resort, pension, other
lodging_type_detail숙소 유형이 other일 때 사용하는 직접 입력값
lodging_name숙소 이름
location숙소 위치 또는 주소
selling_points객실, 전망, 공간, 시설 등 공간 중심 특징 목록, 최대 5개
lodging_service무료 조식, 픽업, 할인 등 서비스·혜택 목록, 최대 5개
mood원하는 광고 분위기
color_preference광고 이미지에서 선호하는 색상
target_audience광고 대상 고객
ad_copy최종 광고 문구
값이 null이거나 빈 배열이면 아직 수집하지 않은 항목입니다. 모델 응답의 brief_updates만 기존 brief에 합쳐서 갱신합니다.

기획 대화 Response Body

필드React에서의 역할
request_id모델 요청을 추적하기 위한 ID입니다. 오류 문의와 로그 확인에 사용할 수 있습니다.
session_id현재 광고 기획 세션 ID입니다.
message_intent사용자의 이번 발화 의도입니다. answer는 현재 질문에 대한 답변, correction은 이전 정보 수정, question은 사용자의 질문, system_event는 시스템 동작을 뜻합니다.
answer_status답변 판정 결과: valid, ambiguous, off_topic, not_applicable
assistant_messageReact 채팅창에 표시할 모델의 다음 질문 또는 안내 메시지입니다.
brief_updates임시 기획서에서 변경할 값입니다. 기존 brief에 합쳐서 저장합니다.
corrected_fields사용자의 수정 요청으로 값이 변경된 항목입니다.
completed_fields입력이 완료된 기획서 항목입니다.
missing_fields아직 입력되지 않은 필수 항목입니다.
current_step이번 응답을 처리한 현재 단계입니다.
next_step다음 질문 단계입니다. 다음 요청의 current_step으로 사용합니다.
is_completetrue이면 기획 질문이 완료된 상태입니다. 확인 버튼을 활성화할 수 있습니다.

광고 초안 Response Body

필드React에서의 역할
id광고 초안 UUID이며 조회·선택 시 draft_id로 사용합니다.
session_id초안이 속한 기획 세션 UUID입니다.
generation_round1은 최초 생성, 2는 재생성 결과입니다.
direction초안 방향: room, emotion, benefit
status생성 상태: pending, processing, completed, failed
image_url화면에 이미지를 표시할 상대 URL입니다. 백엔드 Base URL을 앞에 붙입니다.
mime_type생성된 파일 형식이며 정상 결과는 image/png입니다.
file_size생성 이미지의 byte 크기입니다.
is_selected사용자가 최종 선택한 초안인지 나타냅니다.
error_code생성 실패 시 오류 종류를 나타냅니다.
error_message생성 실패 시 사용자 또는 로그에서 확인할 오류 설명입니다.
created_at초안 레코드 생성 시각입니다.
updated_at초안 상태가 마지막으로 변경된 시각입니다.
completed_at이미지 생성 완료 시각이며 완료 전에는 null입니다.
regeneration_used해당 기획 세션의 재생성 기회를 성공적으로 사용했는지 나타냅니다.

8. 공통 오류 응답

HTTP 상태의미
404기획 세션 또는 광고 초안을 찾을 수 없음
